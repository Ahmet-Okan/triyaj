# Triyaj

Tıp öğrencileri için acil servis vaka oyunu. Hasta sadece şikâyetini söyler; vitaller kapalıdır ve zamanla açılır, her tetkik vaka saatinden süre yer. Doğru tanı, kritik müdahaleler ve kılavuza uygun süreler puanlanır.

**Oyna:** https://ahmet-okan.github.io/triyaj/ (telefonda "Ana ekrana ekle" ile uygulama gibi kurulur)

> Eğitim amaçlı demo, tıbbi tavsiye değildir. Vakalar hekim onayı bekliyor.
